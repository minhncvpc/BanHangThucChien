# Hướng dẫn Cài đặt Ứng dụng Nhập Liệu Tài liệu này hướng dẫn cách đưa mã nguồn vào Google Sheet để tạo ứng dụng nhập liệu. ## Bước 1: Chuẩn bị Google Sheet 1. Tạo một Google Sheet mới (hoặc mở Sheet có sẵn). 2. Đổi tên Sheet đầu tiên thành **Data**. Đây là nơi dữ liệu nhập sẽ được lưu. (Cột A: Thời gian, B: Email, C: Đơn vị, D: Mã NV, E: Số TB, F: Dịch vụ, G: Giá cước, H: Ghi chú, I: Tên NV). Nếu chưa tạo, hệ thống sẽ tự động tạo giúp bạn khi có lượt nhập đầu tiên. 3. Tạo thêm một Sheet mới và đặt tên là **Config**: * **Cột A (A2 trở đi):** Tên Đơn vị (VD: VNPT Cẩm Khê, VNPT Việt Trì...). * **Cột B (B2 trở đi):** Mã nhân viên (VD: CKH001, VTR001...). * **Cột C (C2 trở đi):** Tên nhân viên (VD: Nguyễn Văn A, Lê Hoàng Nam...). * *Lưu ý: Hàng đầu tiên (A1, B1, C1) là tiêu đề. Mỗi dòng tương ứng với một nhân viên thuộc đơn vị đó (có thể gộp ô cột Đơn vị).* ## Bước 2: Thiết lập Google Apps Script 1. Trên thanh menu của Google Sheet, chọn **Tiện ích mở rộng (Extensions)** > **Apps Script**. 2. Trình soạn thảo Apps Script sẽ mở ra. 3. **File Code.gs**: * Mở file `Code.gs` mặc định. * Xóa hết nội dung bên trong. * Copy toàn bộ nội dung từ file `Code.js` trong thư mục này và dán vào. * Nhấn biểu tượng Đĩa mềm (Save) hoặc `Ctrl + S` để lưu. 4. **File index.html**: * Nhấn dấu cộng **(+)** cạnh chữ "Tệp" (Files) bên trái > Chọn **HTML**. * Đặt tên file là `index` (không cần gõ .html, Apps Script tự thêm). * Xóa hết nội dung mặc định. * Copy toàn bộ nội dung từ file `index.html` trong thư mục này và dán vào. * Lưu file lại (`Ctrl + S`). ## Bước 3: Triển khai Ứng dụng (Deploy) 1. Góc trên bên phải, nhấn nút **Triển khai (Deploy)** màu xanh > Chọn **Bài triển khai mới (New deployment)**. 2. Trong hộp thoại hiện ra: * Bấm vào biểu tượng bánh răng (⚙️ Types) > Chọn **Ứng dụng web (Web app)**. * **Mô tả (Description):** Nhập tên tùy ý (VD: App Bán Hàng Thực Chiến v2). * **Thực thi dưới dạng (Execute as):** Chọn **Tôi (Me)** (bắt buộc để ứng dụng có quyền ghi dữ liệu vào Sheet của bạn). * **Ai có quyền truy cập (Who has access):** * Chọn **Bất kỳ ai trong tổ chức của tôi (Anyone within my organization)** (nếu dùng email VNPT/doanh nghiệp). * Hoặc **Bất kỳ ai có tài khoản Google (Anyone with Google account)** / **Bất kỳ ai (Anyone)**. 3. Nhấn **Triển khai (Deploy)**. 4. Google sẽ yêu cầu cấp quyền truy cập. Hãy làm theo các bước: * Chọn **Xem lại quyền (Authorize access)**. * Chọn tài khoản mail Google của bạn. * Nếu hiện cảnh báo "Google chưa xác minh ứng dụng này", chọn **Nâng cao (Advanced)** > **Đi tới ... (không an toàn) (Go to ... (unsafe))**. * Nhấn **Cho phép (Allow)**. 5. Sau khi xong, bạn sẽ nhận được một đường link **Ứng dụng web (Web App URL)** kết thúc bằng `/exec`. 6. Copy link này và mở trên trình duyệt hoặc gửi cho nhân viên sử dụng. --- ## KHẮC PHỤC CÁC LỖI THƯỜNG GẶP KHIẾN ỨNG DỤNG "KHÔNG CHẠY ĐƯỢC" ### 1. Bấm nút "Chạy" (Run) trong Apps Script nhưng không thấy gì hiện ra * **Nguyên nhân:** Trong Google Apps Script, hàm `doGet()` chỉ dùng để trả về mã HTML khi người dùng truy cập qua đường link Web App. Nút "Chạy" trong trình soạn thảo code chỉ chạy ngầm trong máy chủ của Google chứ không thể mở giao diện web. * **Cách khắc phục:** - Nhấn nút **Triển khai (Deploy)** > **Xem các bài triển khai (Test deployments hoặc Manage deployments)**. - Bấm vào đường link **Ứng dụng web (Web app URL)** để mở trang web. ### 2. Màn hình quay tròn mãi ở dòng "Đang tải dữ liệu cấu hình..." * **Nguyên nhân:** - Người dùng mở trực tiếp file `index.html` từ ổ đĩa máy tính (URL bắt đầu bằng `file:///...`) thay vì mở qua link Web App của Google Apps Script (`https://script.google.com/macros/s/.../exec`). - Hoặc Sheet chưa được cấp quyền truy cập. * **Cách khắc phục:** Mở file thông qua đường link Web App đã triển khai trên Google Apps Script. Bản code mới đã bổ sung cơ chế tự ngắt sau 15 giây và hiển thị thông báo lỗi cụ thể thay vì bị đơ. ### 3. Đã sửa code nhưng mở Web App vẫn là phiên bản cũ * **Nguyên nhân:** Google Apps Script lưu cache phiên bản deploy. Nếu sửa code mà không tạo Version mới, link `/exec` vẫn chạy bản code cũ. * **Cách khắc phục:** - Vào **Triển khai (Deploy)** > **Quản lý các bài triển khai (Manage deployments)**. - Nhấn biểu tượng ✏️ **Chỉnh sửa (Edit)** cạnh bài triển khai hiện tại. - Tại mục **Phiên bản (Version)**, chọn **Phiên bản mới (New version)**. - Nhấn **Triển khai (Deploy)** để cập nhật mã mới có hiệu lực ngay lập tức. ### 4. Lỗi "Không thể mở Google Sheet" hoặc dữ liệu không ghi vào Sheet của mình * **Nguyên nhân:** Do hardcode ID Google Sheet cũ. * **Cách khắc phục:** Phiên bản code mới đã được nâng cấp để **tự động kết nối trực tiếp vào Sheet hiện tại** (`getActiveSpreadsheet()`), không bị phụ thuộc vào ID cũ hay phát sinh lỗi phân quyền chéo tài khoản.
